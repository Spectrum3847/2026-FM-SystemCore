# Log keys

Generated by `tools/make_log_key_guide.py` from the comments next to each logged value; edit those, not this file. Every log also carries this list as the `LogKeyGuide` metadata.

Inputs (I) are recorded readings that replay feeds back as-is; outputs are computed and replay recomputes them. `<name>` is filled in at runtime.

## Logged by AdvantageKit and the framework

| Key | Meaning |
|---|---|
| `/DriverStation/*` | Driver Station and match data: enabled, mode, alliance, event, match number and type, joysticks (AdvantageKit) |
| `/SystemStats/*` | Controller CPU, memory, storage, network, CAN bus, IMU, faults, battery, NT clients and clock validity (AdvantageKit) |
| `/RadioStatus/*` | Radio status JSON (AdvantageKit; Wi-Fi keys redacted by RadioStatusRedactor) |
| `/RealOutputs/LoggedRobot/*` | Loop timing: FullCycleMS, UserCodeMS, LogPeriodicMS, GC time (AdvantageKit) |
| `/RealOutputs/Console` | Everything printed to the console (AdvantageKit) |
| `/RealMetadata/*` | Build and robot identity: GitSHA, GitBranch, BuildDate, RobotIdentity, BootId, LogKeyGuide |
| `/Timestamp` | The cycle's robot time (AdvantageKit) |
| `/NetworkInputs/*` | Values read from the dashboard over NetworkTables (LoggedNetwork*), recorded so replay sees what the robot saw |
| `/Params/*` | Tuned values from src/main/deploy/params/*.json and their dashboard overrides, by group and name (Params) |
| `/RealOutputs/Scheduler/*` | Code timings (Telemetry.time/timeEnd), once a second: the key is the worst span of that second, <key>Mean the mean. RobotPeriodic is the whole loop; Periodic/<Subsystem> each subsystem |
| `/RealOutputs/Summary/*` | The match summary (MatchSummary), once a second: battery, brownouts, loop, DS drops, CAN/<bus>/Drops|DownSeconds|BusOffs, Devices/*, Auto/*, Alerts/*, PeakTempC/<device>; see docs/match-summary.md |
