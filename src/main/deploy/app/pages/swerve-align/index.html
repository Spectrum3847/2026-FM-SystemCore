Swerve Alignment

Reads the CANcoders live and prints the offsets line for the robot config.

Not connected

1 Pin the modules straight

Point every wheel you are aligning straight forward, bevel gears all on the same side, and hold it there: the module’s alignment pin if it has one, else a straight edge along the wheels.

Tick each item as you do it. None of these are checked by software. They are the part only you can verify.

2 Check the live readings

Angles below are what the robot currently believes. With the modules pinned and a good alignment deployed, they should all read close to 0°.

3 Capture

Averages half a second of encoder readings and works out what the offsets should be. Nothing is written yet.

Modules to align

Unticked modules keep the offset they already have in the code. Untick the ones you have not pinned, after replacing a single module for instance.
